# Hola, soy Carolina Caballero ✨

Analista de datos en Ciudad de México. Convierto datos dispersos en respuestas claras.

## En qué trabajo 🔭

**Pipeline de Datos Patrimoniales** (en curso)

Pongo orden a mis finanzas personales: reúno ingresos, cuentas e inversiones repartidos en varias plataformas y monedas en una sola fuente de verdad, con arquitectura Medallion (Bronce, Plata, Oro). Uso Python (Pandas) para la ingesta, MySQL para transformar y modelar los datos en un esquema estrella, y Power BI para visualizarlos.

Como trabajo con datos financieros sensibles, la privacidad es parte del diseño: cada campo sensible recibe un tratamiento antes de llegar al análisis, y lo que publico sale de un modo demo con datos sintéticos. El código estará disponible aquí próximamente.
